# Avatars

The prototype shows real photos from [Unsplash](https://unsplash.com/license) (free to use, no
attribution required), loaded by `../people.js`. The illustrations below are the fallback used if
a photo can't load.

These portraits were generated with [DiceBear](https://www.dicebear.com/) using the
[Notionists](https://www.dicebear.com/styles/notionists/) style by Zoish.

- Design: Notionists by Zoish, licensed [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain).
- Generator: DiceBear by Florian Körner, MIT licence.

Each file is named after a sample person in the Staffora prototype (for example `amaya-silva.svg`).
No attribution is required, but credit is appreciated.
